# Reference

| Task | Location |
| --- | --- |
| Customize keyboard bindings | File → Program Preferences → Keyboard Shortcuts |
| Find gestures for the current tool | Timeline → Command Helper |
| Change recovery and save intervals | File → Program Preferences → Saving Options |
| Inspect pen input | File → Program Preferences → Tablet Diagnostics |
| See what was skipped during FLA import | File → FLA Import Report |

Use **.ltoon** for editable projects. FLA import retains supported artwork and reports omitted or approximated features. FLA export is experimental. LibreToon also exports PNG sequences, sprite sheets, SVG, and video formats including MP4, MKV, AVI, MOV and GIF.

If video export asks for FFmpeg, use the setup prompt or choose an existing executable. If the canvas is slow with lighting or post-processing, reduce viewport quality or prepare the preview for the range you are reviewing.
