# LibreToon User Manual

This guide covers LibreToon 0.8.0. Start with a short animation, then use the chapters to look up individual tools.

1. Download the package for your platform from [Releases](https://github.com/alvillafm/LibreToon/releases). Launch LibreToon.
2. Choose **New Project** from Home. Set the stage size, frame rate, and duration.
3. Draw with the brush on the first frame. Select a later frame in the timeline and use **Insert blank keyframe** to draw a second pose.
4. Press Play to check the timing. Save the editable project as a **.ltoon** file.
5. Choose an export format from **File**. Video export requires a configured FFmpeg executable. PNG sequences can be exported directly.
